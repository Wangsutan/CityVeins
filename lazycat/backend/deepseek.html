还没有 DeepSeek Key？

  1. 打开 DeepSeek 开放平台 · API Keys
  2. 登录后「创建 API Key」，得到一串以 sk- 开头的字符
  3. 复制它，填到上面的输入框里保存（这串只在创建时显示一次，丢了就重新建一个）

按量计费，一份报告通常只花几分钱。账户里余额为 0 时 AI 报告会报 「AI API调用失败」，充值后即恢复。

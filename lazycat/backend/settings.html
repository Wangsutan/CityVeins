高德地图

  1. 打开 高德开放平台控制台
  2. 「应用管理 → 我的应用 → 创建新应用」
  3. 添加 Key，服务平台选择 Web 服务（不是 Web 端 JS API）
  4. 若该 Key 设置了 IP 白名单，需把本机/本盒子的出口公网 IP 加进去
  5. 复制生成的 Key，填到上面并保存

DeepSeek

  1. 打开 DeepSeek 开放平台 · API Keys
  2. 创建 API Key（以 sk- 开头的一串字符），复制
  3. 填到上面的 DeepSeek 输入框并保存
两列权重的区别（重要）
· 客制化权重：只影响评分。留空表示使用基础权重。改它不会改变抓取范围，是推荐的调整方式。
· 基础权重：既影响评分，也决定抓取范围 —— 系统按「大类权重 ≥ 0.4」决定该大类下的 POI 是否被抓取。修改大类行的基础权重会直接改变下一次抓取收录哪些业态。

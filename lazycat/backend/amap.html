还没有高德 Key？

  1. 打开 高德开放平台控制台（需先注册并实名认证）
  2. 「应用管理 → 我的应用 → 创建新应用」
  3. 在应用里「添加 Key」，服务平台选择 Web 服务 —— 注意不是「Web 端 (JS API)」，选错了城脉调不通
  4. 若该 Key 设了 IP 白名单，要把本设备的出口公网 IP 加进去； 不加白名单就不受此限制
  5. 复制生成的 Key，填到上面的输入框里保存

高德「Web 服务」有免费额度，日常查询足够用；用量超额后需要在控制台自行充值。

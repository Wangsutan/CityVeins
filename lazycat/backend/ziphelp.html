ZIP 使用说明

「打包下载 ZIP」下载回来的压缩包，怎么解开

← 返回设置

城脉的「打包下载 ZIP」会把这条记录下的全部文件打成一个压缩包 （POI 数据、评分、汇总、评估报告、AI 报告）。压缩包里的 HTML 报告 用浏览器打开就能看，不需要联网。下面按系统分别说明。

🪟 Windows Windows 10 / 11

  1. 在「下载」文件夹里找到刚下载的压缩包
  2. 右键压缩包 →「全部解压缩…」
  3. 选择一个文件夹 → 点「提取」
  4. 进入解压出来的文件夹，双击里面的 .html 报告，用浏览器打开

提示：不要直接在压缩包里双击 HTML —— 那样打开的是临时文件， 报告里的相对引用可能失效。

🍎 macOS Finder

  1. 在「下载」里找到压缩包
  2. 双击压缩包，系统会自动解压到同目录（生成同名文件夹）
  3. 进入该文件夹，双击 .html 报告用浏览器打开

提示：如果双击没反应，说明压缩格式没被识别， 可以右键 →「打开方式」→「归档实用工具」。

🐧 Linux 桌面或终端

  1. 命令行：unzip 文件名.zip（没装的话先 apt install unzip）
  2. 图形界面：在文件管理器里右键压缩包 →「提取到此处」
  3. 进入解压出来的文件夹，用浏览器打开 .html 报告

提示：报告是 UTF-8 编码，只要浏览器不是太旧都能正常显示中文。

📱 Android 手机 / 平板

  1. 先装一个支持解压的文件管理器，例如 ZArchiver（免费）
  2. 用它在「下载」目录里长按压缩包 →「解压到当前目录」
  3. 解压完成后，进入文件夹点 .html 报告 → 选择用浏览器打开

提示：手机自带文件管理器多数不能解压 zip， 装 ZArchiver 最省事；解压后在浏览器里看报告和电脑上是一样的。

只想看某个文件、不想解压整个包？到 记录袋 里点那条记录的「文件清单」， 可以逐个预览或单独下载 —— 报告还能直接在页内看，不必先下载。
